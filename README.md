# OrbitWatch

OrbitWatch is a modern web application for visualizing Earth and tracking satellites in real time.

## Features

- 🌍 Interactive 3D Earth
- 🛰️ Real-time satellite positions
- 🔍 Satellite search
- 📊 Orbital information
- 🌙 Day/Night visualization
- 📈 Orbit paths
- ⭐ Favorites
- 🚀 Responsive UI
