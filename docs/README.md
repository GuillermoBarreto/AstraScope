# OrbitWatch Documentation

This folder holds project notes and architecture decisions for the OrbitWatch foundation milestone.

## Current scope

- Monorepo structure for frontend and backend
- Vite + React + TypeScript frontend baseline
- FastAPI backend with CORS and health endpoint
- Shared environment configuration pattern

## Future milestones

- Satellite data integration
- 3D Earth visualization
- Search and filtering experience
- Deployment and monitoring
